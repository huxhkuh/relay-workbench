# Source provenance and license boundaries

Version 0.6.0 removes the previously imported compiled renderer and its fonts.
The full interface is maintained in src/: application state, chat, settings, approvals,
agent controls, productivity dialogs and workbench. tools/build.cjs generates every
frontend asset and backend dependency bundle. No patching of a legacy bundle remains.
The Relay arrow icon is original and generated by tools/generate-icon.cjs without fonts.
The interface uses system fonts and redistributes no font files.

The project retains its existing MIT-licensed desktop modules and attribution to
Boau Code contributors, with new Relay Workbench contributions under the same license.
Historical IPC, Windows profile, executable and registry identifiers remain for compatibility.
They do not mean the original application binary is reused. The branded NSIS and portable
releases launch Relay-Workbench.exe; the compatibility folder package retains Boau-Code.exe.

## Third-party components

- npm dependencies are pinned in package-lock.json. Bundled dependencies have their
  actual license texts collected in desktop/vendor/WORKBENCH-LICENSES.txt during builds.
- ACP catalog metadata is a discovery snapshot from agentclientprotocol/registry.
  Its Apache-2.0 text is in licenses/ACP-REGISTRY.txt. Agent entries have independent licenses.
- Electron is fetched through its pinned official npm package; its license and Chromium
  notices remain in Windows packages. Electron itself is not built from C++ source here.
- The optional Claude Agent SDK is installed separately under vendor terms using the
  pinned manifest and lockfile in tools/claude-sdk/. Neither that SDK nor a provider CLI
  is bundled into the open-source app or the exported source archive.
- Coding-provider brands describe interoperability only. This is an independent project.

The default source/build pipeline no longer depends on the original archive, its
compiled UI, fonts, proprietary runtime bundles or a developer's previous installation.
The previous missing-renderer-source release blocker is resolved. Provider accounts,
third-party distribution rights and trademark ownership are not granted by this project.
