# Relay Workbench 0.6.0

סביבת עבודה עצמאית לסוכני קוד ב־Windows, עם ממשק בעברית ובחירת סוכן לכל שיחה.
כל הממשק נבנה כעת מקוד מקור בתיקיית src. חבילת React המקופלת, הפונטים והקובץ
המקורי אינם חלק מהבנייה או מחבילת המקור. התוכנה אינה מוצר רשמי של ספקי הסוכנים.

## הורדה

- [מתקין Windows x64](https://github.com/huxhkuh/relay-workbench/releases/download/v0.6.0/Relay-Workbench-Setup-0.6.0-x64.exe)
- [גרסה ניידת ZIP](https://github.com/huxhkuh/relay-workbench/releases/download/v0.6.0/Relay-Workbench-0.6.0-x64.zip)
- [אתר ההורדה](https://huxhkuh.github.io/relay-workbench/)

המתקין הוא גרסת פיתוח ללא חתימת מפרסם. ערכי SHA-256 נמצאים בדף המהדורה ובאתר.
כלי הסוכנים וחשבונותיהם מותקנים בנפרד; ההתקנה אינה מוסיפה מנוי או מכסת AI.

## הפעלה מפיתוח

נדרשים Node.js 26, npm ו־Git. מתוך תיקיית הפרויקט:

```powershell
npm ci
npm run build
npm test
npm start
```

יש להתקין בנפרד את כלי הסוכן הרשמי. אפשר לבחור את קובץ Codex בהגדרות אם לא זוהה.
ל־Claude נדרשת גם התקנת SDK נפרדת באמצעות npm run setup:claude; ההתקנה אינה רוכשת
מנוי או מכסה. השימוש דורש חשבון מתאים ונשאר כפוף לתנאי הספק.

## יכולות שנשמרו

שיחות והיסטוריה עם חיפוש, שינוי שם, הצמדה וארכוב; הזרמת Markdown וקוד; אישורים,
שאלות וטופסי MCP; חשבון, מודלים וסביבת Windows; העברת משימות בין סוכנים;
עורך קבצים, חיפוש, מסוף פקודות, Git ומשימות רקע; הוראות, סקילים, שחזור ואבחון.

Ctrl+K פותח את מרכז העבודה, Ctrl+, את ההגדרות ו־Ctrl+Shift+P את סביבת הפיתוח.
Enter שולח הודעה ו־Shift+Enter מוסיף שורה. טיוטת העברה אינה נשלחת עד שליחה מפורשת.
החלפת סוכן אינה מעבירה פרטי התחברות. השיחות והגיבויים הקיימים נשמרים ב־Boau Code.

npm run package:win מכין חבילת Windows מ־Electron רשמי; כלים מסחריים אינם מצורפים.
npm run export:source מכין עותק מקור ללא התקנות, שיחות וסודות. הוא אינו מפרסם ברשת.
הגרסה היא גרסת פיתוח לא חתומה. פירוט היכולות, הבדיקות, הפרטיות והרישוי נמצא ב־README.md.
